# Absolute fish biomass

The "Analysis" folder contains the code used to generate proportional allochthony under two different scenarios. 
The files "MixSIAR_Lake+Species.rds" and "MixSIAR_Lake+Trait.rds" are not included in this repository because they exceed the file size limit for upload.

The "Figures" folder contains all figures presented in this study.

The "Generate figures" folder contains all code and data used to generate the figures presented in this study.
